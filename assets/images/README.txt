No hero background photo is bundled with this project (avoiding
unlicensed stock imagery). The hero section instead uses a CSS
gradient + animated SVG "collection route" as its background,
defined directly in index.html / css/style.css. Drop a licensed
JPG/WEBP here (e.g. hero-background.jpg) and reference it from
.hero in css/style.css if you'd prefer a photographic hero.
